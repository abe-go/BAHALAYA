# BAHALAYA
### Ultrasonic Sensor-Driven Flood Control Innovation

## Project Overview

BAHALAYA is an Arduino-based flood monitoring and control system designed to monitor rising water levels using ultrasonic sensor technology. It aims to provide real-time water level monitoring and automated responses to help improve flood management and awareness.

## Objectives
- Monitor water levels using ultrasonic sensors.
- Detect changes in water levels.
- Provide visual alerts through LED indicators.
- Automate flood control mechanisms based on detected water levels.

## Hardware Components
- Arduino Uno
- Ultrasonic Sensor
- LCD I2C Display
- Green, Yellow, and Red LEDs
- MOSFET Module
- Water Pump
- Power Supply

## Technologies Used
- Arduino IDE
- Embedded C/C++
- Ultrasonic Sensing
- Electronics and Automation

## System Features
- Real-time water level monitoring
- Water level status indicators
- Rapid water level rise detection
- Automated water pumping mechanism
